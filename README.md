# Dynamic Survey and Data Collector

This is a Python script that showcases how to use nested loops and dynamic lists to build a simple survey system. It allows users to define custom questions and collect multiple responses.

## How it works:
1. It prompts the user to define the number of questions and type them in.
2. It stores the questions in a list called `ques`.
3. It starts a `while` loop to collect answers from multiple participants.
4. For each participant, a nested `for` loop iterates through the defined questions to collect answers and store them in a temporary list.
5. All responses are saved together in a main 2D list called `data` until the user decides to stop.

## What I practiced in this project:
- **Nested Loops:** Running a `for` loop inside a `while` loop to handle repetitive structural inputs.
- **2D Lists (Matrices):** Storing lists inside a list to create a structured database-like format.
- **Dynamic User Inputs:** Letting the user define the program's flow by creating custom questions.
